# 🐾 Ada Adventures

Um jogo 2D desenvolvido em Unity onde o jogador controla um cachorro em
uma aventura repleta de desafios, obstáculos e exploração.

------------------------------------------------------------------------

## 📖 Sobre o Projeto

**Ada Adventures** é um jogo eletrônico 2D desenvolvido utilizando a
engine **Unity** e linguagem **C#**.

O projeto apresenta uma experiência de plataforma onde o jogador
controla um personagem canino, explorando cenários, enfrentando
obstáculos e avançando por diferentes fases.

------------------------------------------------------------------------

## 🎮 Gameplay

O jogador controla um cachorro que deve:

-   🐕 Explorar cenários;
-   ⭐ Coletar elementos durante as fases;
-   🧱 Superar plataformas e obstáculos;
-   👾 Interagir com inimigos;
-   🚀 Avançar entre fases.

------------------------------------------------------------------------

## ✨ Funcionalidades

### 🐶 Controle do Personagem

-   Movimentação horizontal;
-   Sistema de pulo;
-   Controle de física;
-   Interação com plataformas.

### 👾 Sistema de Inimigos

Controle de inimigos através de scripts C#.

### 🎬 Gerenciamento de Cenas

-   Menu principal;
-   Troca de fases;
-   Controle de telas.

### ⭐ Sistema de Feedback

Sistema de avaliação utilizando estrelas.

# 🚀 Como executar

## Pré-requisitos

-   Unity Hub
-   Unity Editor compatível
-   Git instalado

## Clonar

``` bash
git clone https://github.com/PalomaCSantoss/ada-adventures.git
```

Entre na pasta:

``` bash
cd ada-adventures
```

Abra o projeto no Unity Hub e execute pelo botão **Play**.
